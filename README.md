# 🎵 Spotify Clone - Frontend UI

A pixel-perfect, responsive **Spotify Web Player** clone built with pure HTML, CSS, and Vanilla JavaScript. This project focuses on replicating the modern "dark mode" aesthetic and the card-based layout of the world's most popular music streaming service.



## 🚀 Live Demo
**[Check out the Live Site here!](https://your-username.github.io/your-repo-name)**

---

## ✨ Key Features

* **Three-Panel Layout:** A clean separation between the Navigation Sidebar, the Library Manager, and the Main Content area.
* **Custom Media Player:** A fully designed playback bar featuring a custom-styled seek bar, volume controls, and playback buttons.
* **Hover Interaction:** Dynamic hover states on playlist cards and navigation links for an authentic app feel.
* **Responsive Cards:** "Recently Played" and "Trending" sections that utilize CSS Flexbox for organized content delivery.
* **Dark Mode Aesthetic:** High-contrast UI designed for readability and visual comfort.
